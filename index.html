A few helpful things

Good to know.

How do I watch videos together?

Create or join the same room, add a YouTube video and use the shared playback controls. All members need to be online.

Do I need to enter a YouTube API key?

No. YSEFY uses its secure server-side YouTube connection. Your API key stays in Vercel and is never entered here.

Are rooms private?

Room visibility is a setting, but actual privacy depends on your Firebase Authentication setup and Realtime Database security rules. Do not store passwords as plain text.

Why might playback not start?

Some videos restrict embedding, require age verification or are unavailable in certain regions. Try another video if the player refuses to load.

Can I use YSEFY on my phone?

Yes. The layout is designed mobile-first and adapts to smaller screens.
